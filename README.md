# tg-channel-reader skill

Agent skill for exporting public Telegram channel posts, media metadata, reactions, links, and Discussion Widget comments — no Telegram login required. Backed by [`tg-channel-reader`](https://github.com/toolittlecakes/tg-channel-reader).

Works with any agent harness that supports the [Agent Skills](https://agentskills.io) format (Claude Code, Codex, OpenCode, etc.).

## Install

```bash
git clone https://github.com/toolittlecakes/tg-channel-reader-skill.git ~/.claude/skills/tg-channel-reader
```

The CLI runs via `npx -y tg-channel-reader` on demand — no separate install step.
